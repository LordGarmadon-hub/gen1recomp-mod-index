# Summary IVs

Show all six IVs inline in the orange Summary stat area without changing the stat totals.

For **FireRed and LeafGreen** in gen1recomp (mod API 2). This experimental mod was developed with AI assistance using OpenAI Codex. Back up your saves before use.

[Features, screenshots and instructions](https://github.com/CapnJames95/gen1recomp-mod-releases#mod-summary-ivs) · [Download 0.1.0](https://github.com/CapnJames95/gen1recomp-mod-releases/releases/download/v1.0.0/summary-ivs-0.1.0.zip)

Import the individual ZIP through **MODS → Import mod .zip**, enable it and restart. Runtime Lua source and original notices are included in the ZIP.
