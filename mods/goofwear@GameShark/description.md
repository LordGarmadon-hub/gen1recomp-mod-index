# GameShark Compatibility

GameShark is a cheat and utility mod for Gen1Recomp.

It provides an in-game GameShark menu with features such as item and Pokémon manipulation, teleportation, movement cheats, battle-related options, and additional utilities.

The mod supports Generation I, Generation II, and Generation III games. Recent releases also include features for Pokérus, instant egg hatching, FireRed shiny Pokémon, and additional FireRed functionality.

The mod requires the `engine_internals` permission because it integrates directly with internal Gen1Recomp systems.
