
# Better Info

Better Info overhauls the user interface of Pokémon Gen 1 Recomp while preserving the original game's visual style.

Features include:

- **Expanded Pokédex:** a grid layout and multi-page entries showing base stats, learnsets, and evolutions.
- **Improved Summary Screen:** a redesigned stats screen with dedicated move information.
- **Battle Move Details:** displays move type, power, accuracy, and PP.
- **Move Relearner:** adds an NPC to the second floor of Celadon Mansion.

The features can be configured in the mod options. Changes to options take effect after restarting the game.

Compatibility: Pokémon Gen 1 Recomp. The original manifest declares conflicts with Kanto Ascendant and Modern Pokédex UI.
