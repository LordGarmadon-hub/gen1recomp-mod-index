# Day Care Viewer

Inspect daycare and breeding details, manage deposited Pokémon and teleport to daycare.

For **FireRed and LeafGreen** in gen1recomp (mod API 2). This experimental mod was developed with AI assistance using OpenAI Codex. Back up your saves before use.

[Features, screenshots and instructions](https://github.com/CapnJames95/gen1recomp-mod-releases#mod-day-care-viewer) · [Download 0.2.1](https://github.com/CapnJames95/gen1recomp-mod-releases/releases/download/v1.0.0/daycare-viewer-0.2.1.zip)

Import the individual ZIP through **MODS → Import mod .zip**, enable it and restart. Runtime Lua source and original notices are included in the ZIP.
