# Quick Heal Party

Heal one Pokémon or the whole party with owned medicine after reviewing the cost.

For **FireRed and LeafGreen** in gen1recomp (mod API 2). This experimental mod was developed with AI assistance using OpenAI Codex. Back up your saves before use.

[Features, screenshots and instructions](https://github.com/CapnJames95/gen1recomp-mod-releases#mod-quick-heal-party) · [Download 0.1.0](https://github.com/CapnJames95/gen1recomp-mod-releases/releases/download/v1.0.0/quick-heal-party-0.1.0.zip)

Import the individual ZIP through **MODS → Import mod .zip**, enable it and restart. Runtime Lua source and original notices are included in the ZIP.
