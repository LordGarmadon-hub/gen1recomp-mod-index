
# Dex Radar

Dex Radar lists the wild Pokémon available on your current map, helping you see which species can be encountered in grass, water, and while fishing.

## Features

- Lists wild Pokémon for the current map in Pokémon Red, Blue, and Yellow.
- Supports Pokémon Gold, including Headbutt, Rock Smash, the Bug-Catching Contest pool, and roaming legendary Pokémon.
- Shows levels and encounter rates for species already seen.
- Hides unseen species as silhouettes with question marks until they have been discovered.
- Displays owned Pokémon with a Poké Ball mark.
- Supports configurable display options and a keyboard shortcut, enabled by default with R.
- Provides an API that other mods can use to query encounter information and Pokédex ownership.

## How to open

Open START and select D.RADAR, or use the configured hotkey while exploring the overworld.

Opening the radar does not mark Pokémon as seen or owned.
