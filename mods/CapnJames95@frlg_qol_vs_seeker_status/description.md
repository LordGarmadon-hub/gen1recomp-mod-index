# VS Seeker Readiness

Show VS Seeker battery charge and readiness in its Bag description.

For **FireRed and LeafGreen** in gen1recomp (mod API 2). This experimental mod was developed with AI assistance using OpenAI Codex. Back up your saves before use.

[Features, screenshots and instructions](https://github.com/CapnJames95/gen1recomp-mod-releases#mod-vs-seeker-readiness) · [Download 0.1.1](https://github.com/CapnJames95/gen1recomp-mod-releases/releases/download/v1.0.0/frlg_qol_vs_seeker_status-0.1.1.zip)

Import the individual ZIP through **MODS → Import mod .zip**, enable it and restart. Runtime Lua source and original notices are included in the ZIP.
